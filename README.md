# Cloud Academy

Самообучающаяся академия навыков для Claude: создание Skills по любой теме, оценка, тестирование и память уроков.
Сайт собран из артефакта claude.ai и работает как обычная статическая страница.

## Файлы

- `index.html` — приложение целиком (стили, логика, библиотека навыков, память, каталог из 271 открытого навыка).
- `standalone.js` — замена среды claude.ai вне её: генерация через Anthropic API, скачивание файлов через браузер, хранение данных в `localStorage`.

## Запуск

Локально:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Публикация: GitHub Pages (Settings → Pages → Deploy from a branch → ветка и папка `/`), Netlify, Vercel или любой статический хостинг.

## Как работает вне claude.ai

- Библиотека, Premium, Память, информация и скачивание SKILL.md / ZIP работают сразу.
- Для создания навыков и тестов нажмите «Ключ API» и вставьте ключ Anthropic (console.anthropic.com).
  Ключ хранится только в браузере посетителя и отправляется напрямую на `api.anthropic.com`.
  Модели по умолчанию: `claude-sonnet-5-5` (основная) и `claude-haiku-5-5` (быстрая), меняются там же.
- Новые навыки и уроки сохраняются в `localStorage` этого браузера. Навыки, встроенные в `index.html`, видны всем посетителям.
