# Academy Skills

Самообучающаяся академия навыков для Claude: библиотека Skills, оценки, память уроков, каталог из 770 открытых навыков и голосовой помощник.

Сайт собран из артефакта claude.ai «Academy Skills» и работает как обычный статический сайт: без сервера, базы данных и сборки.

## Как это работает

Сайт — открытая витрина: библиотека навыков, Premium, память, каталог и скачивание навыков доступны всем без регистрации.

Создание навыков, тесты и ответы помощника работают в артефакте Academy Skills на claude.ai. Кнопки «Создать навык», «Запустить тест» и «Открыть в Claude» открывают его в новой вкладке, а тема навыка копируется в буфер обмена. Посетитель входит в свой аккаунт Claude, и расходуются лимиты его подписки. Ключ API и кабинет Anthropic Console не нужны ни владельцу сайта, ни посетителям.

Чтобы ссылка работала у других людей, в claude.ai откройте артефакт → «Поделиться» → доступ «Всем, у кого есть ссылка».

## Запуск на своём компьютере

Распакуйте архив и дважды щёлкните `index.html`. Для установки как приложения и офлайн-режима запустите локальный сервер:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Публикация в интернете (бесплатно)

**GitHub Pages:** репозиторий → Settings → Pages → Source: *Deploy from a branch* → ветка `main`, папка `/ (root)` → Save. Через 1–2 минуты сайт будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`.

**Netlify Drop:** откройте [app.netlify.com/drop](https://app.netlify.com/drop) и перетащите папку сайта в окно. Ссылка появится сразу.

Также подойдут Vercel, Cloudflare Pages или любой хостинг статических файлов.

## Файлы

| Файл | Что это |
| --- | --- |
| `index.html` | Приложение целиком: оформление, логика, встроенные навыки, память, каталог |
| `standalone.js` | Замена среды claude.ai: переход к созданию навыков в Claude, скачивание файлов, хранение в браузере |
| `manifest.webmanifest`, `sw.js`, `icon*.png`, `icon.svg`, `favicon.ico` | Установка как приложение и офлайн-кэш |
| `tools/build.py` | Пересборка `index.html` из новой версии артефакта |

## Чем этот сайт отличается от версии в claude.ai

- Нет аккаунтов, подписки и кабинета администратора: они работают только в claude.ai.
- Создание навыков и тесты открывают артефакт в claude.ai.
- Встроенные навыки берутся из артефакта на момент сборки. Новые навыки появятся на сайте после пересборки.
- Еженедельное автообновление знаний работает в claude.ai. Чтобы перенести его на сайт, пересоберите сайт.

## Как обновить сайт после изменений артефакта

1. Сохраните HTML новой версии артефакта (например, попросите Claude Code прочитать артефакт).
2. Выполните `python3 tools/build.py путь/к/artifact.html index.html`.
3. Загрузите обновлённый `index.html` на хостинг.
