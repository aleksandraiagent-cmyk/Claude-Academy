# Academy Skills

Самообучающаяся академия навыков для Claude: создание Skills по любой теме, оценка, доработка до 9+, тесты, память уроков, каталог из 770 открытых навыков и голосовой помощник.

Сайт собран из артефакта claude.ai «Academy Skills» и работает как обычный статический сайт: без сервера, базы данных и сборки.

## Быстрый запуск на своём компьютере

1. Скачайте папку сайта (кнопка **Code → Download ZIP** на GitHub или готовый архив).
2. Распакуйте и дважды щёлкните `index.html`. Сайт откроется в браузере.
3. Откройте меню **☰ → «Ключ Claude API»** и вставьте свой ключ с [console.anthropic.com](https://console.anthropic.com/settings/keys).

Без ключа работают библиотека, Premium, память, каталог, скачивание навыков и голосовые команды. С ключом работают ещё создание навыков, тесты и ответы помощника.

Чтобы работала установка сайта как приложения и офлайн-режим, запустите его через локальный сервер:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Публикация в интернете (бесплатно)

**GitHub Pages:** репозиторий → Settings → Pages → Source: *Deploy from a branch* → ветка `main`, папка `/ (root)` → Save. Через 1–2 минуты сайт будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`.

**Netlify Drop:** откройте [app.netlify.com/drop](https://app.netlify.com/drop) и перетащите папку сайта в окно. Ссылка появится сразу.

Также подойдут Vercel, Cloudflare Pages или любой хостинг статических файлов.

## Файлы

| Файл | Что это |
| --- | --- |
| `index.html` | Приложение целиком: оформление, логика, встроенные навыки, память, каталог |
| `standalone.js` | Замена среды claude.ai: Claude API по ключу посетителя, скачивание файлов, хранение в браузере |
| `manifest.webmanifest`, `sw.js`, `icon*.png`, `icon.svg`, `favicon.ico` | Установка как приложение и офлайн-кэш |
| `tools/build.py` | Пересборка `index.html` из новой версии артефакта |

## Чем этот сайт отличается от версии в claude.ai

- Все разделы открыты: нет аккаунтов, подписки и кабинета администратора, им нужен сервер claude.ai.
- Генерация идёт через ключ Claude API посетителя. Ключ хранится только в его браузере и отправляется только на `api.anthropic.com`. Запросы оплачиваются по тарифам Anthropic API.
- Модели по умолчанию: `claude-sonnet-5-5` (основная) и `claude-haiku-5-5` (быстрая). Их можно сменить в окне ключа.
- Новые навыки и уроки сохраняются в браузере (localStorage), а не на сервере. Важные навыки скачивайте архивом.
- Еженедельное автообновление знаний работает только в версии claude.ai. Чтобы перенести обновления на сайт, пересоберите его (ниже).

## Как обновить сайт после изменений артефакта

1. Сохраните HTML новой версии артефакта (например, попросите Claude Code прочитать артефакт).
2. Выполните `python3 tools/build.py путь/к/artifact.html index.html`.
3. Загрузите обновлённый `index.html` на хостинг.
